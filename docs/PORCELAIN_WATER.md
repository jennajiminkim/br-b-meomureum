# v0.4.3 · 물결과 도자기 소리 재편집

사용자 설명: 클리나멘의 원음 재사용 허락은 없으며, 맑은 도자기 접촉음과 물의 질감을 참고해 새로운 소리를 원함. 따라서 첨부 작품 영상·추출 M4A는 배포/샘플링에 사용하지 않았음. 참고는 접촉음의 불규칙성·높이 차이·잔향과 수면 움직임이라는 방향뿐임. 작가 목소리/음성을 복제하거나 분석 데이터를 학습한 모델은 없음.

## 구현

- 기존 사용 권한을 확인한 ceramicCups2/kikuchiyo(CC0) 녹음으로 small/middle/large/pair4개를 새로 편집. 크기에 따른 음높이 변형(1.12/1.0/.86), EQ, 부드러운 피크 제어, 약0.8초의짧은 반사장 필터 사용. 원래 도자기 녹음을 기반으로 잔향을 가공한 것이며 새 실물 도자기4종을 녹음한 것은 아님. pair는2접촉을0.28초간격으로 하나의파일안에 믹스.
- 같은파일을 연달아 고르지 않으며, 좌우±.28 및음량범위 .86~1.04 변동. 첫1.8~3.5초, 이후4.8~10.5초간격. 매번소리가같은시간/위치에서나오지않음. 물결배경은64초루프를무작위위치에서시작.
- 물은 기존 Water Waves/transitking(CC0)4종에서편집한water-lapping-v041.mp3의물결구간을재배열.100Hzhighpass/2300Hzlowpass, 약2.5~4.6초간격, 겹침/여백/음량차이, 루프경계연결로64초바탕을만듦. 흐르는시냇물이나원작영상물소리를넣지않음.
- 실제재생에는동시에액센트파일1개만허용. 의도된2접촉은pair파일안에존재. 일시정지·공간변경·종료시액센트정지, 이전공간잔향분리.배경만부드럽게전환. 8초미리듣기는1.7초middle,5.2초다른클립을배치.세션과미리듣기분리유지.
- 숲소리,9개세션의통일된한국어안내음성,대본,화면디자인유지. 인앱소개에영감의출처와실제음원출처·편집내용구분.

## 출처와 재현

원음들은v0.4.1에확인한동일CC0파일. 출처와당시편집과정은AUDIO_REMIX.md. 새입력파일SHA256은porcelain-water-checks.json.

- Ceramic: https://freesound.org/people/kikuchiyo/sounds/214186/ (ceramicCups2.wav, 공개HQ미리듣기기반)
- Water: https://opengameart.org/content/water-waves (transitking, 제출qubodup; 원본freesound11505의wave01~04)
- CC0: https://creativecommons.org/publicdomain/zero/1.0/
- tools/audio/porcelain_water_mix.py를실행(numpy/ffmpeg필요). 배포의기존CC0편집물2개만입력으로사용하므로원작영상없이재현가능. 결과는192kbpsstereoMP3,4개액센트+64초물결바탕+30초검토믹스.
- `dist/assets.js`에서경로지정, `dist/audio-mix.js`에서간격/gain/pan조절. loadRecordings는arraybank를평탄화해각파일을디코딩·캐시.

## 검증 한계

모든출력을MP3로인코딩한뒤다시디코딩,유한파형/비제로/peak<1/길이확인. 새bank의연속중복방지·단일액센트·로더배열처리와기존세션/음성회귀검사실행. 자연음의실제휴대폰청취·주관적청명함·영상과의청감적합성은미검증.30초검토믹스는기본자연음35%를모사한고정배치이며실제세션은범위안에서변동. 외부영상과소리를동일하게재현했다고주장하지않음.
