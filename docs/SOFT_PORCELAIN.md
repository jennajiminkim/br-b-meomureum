# v0.4.4 · 날카로운 도자기 소리 완화

사용자 청취 결과: v0.4.3 물소리는 원하는 소리로 확인됐습니다. 도자기 소리는 날카로워 명상을 방해하며, 낮은 ‘두웅’ 공명과 청명한 여운을 원한다는 피드백을 받았습니다.

## 변경한 것

- 도자기 녹음을 낮은 음역으로 가공하고, 높은 접촉음을 감쇠했습니다. 80ms에 걸쳐 부드럽게 시작하며 약 2.83초에 걸쳐 여운이 사라집니다.
- 가공 녹음 22%와 자체 설계한 낮은 공명 78%를 결합했습니다. 기본 공명은 245/275/310Hz이며, 작은 비정수 배음과 감쇠를 사용합니다. 실제 현장에서 이 소리를 그대로 녹음한 것은 아닙니다.
- 액센트 gain을 1.1에서 0.5로 낮췄습니다. 파일의 최대 진폭도 약 0.48에서 0.25로 줄었습니다. 재생 gain까지 고려한 접촉 순간의 피크는 약 12dB 이상 낮지만, 낮은 몸통 공명을 보강했으므로 전체 체감 음량이 같은 비율로 감소했다는 뜻은 아닙니다.
- 짧게 두 번 부딪히는 pair 파일은 앱 재생 목록에서 제외했습니다. 단일 공명 3종을 사용하며, 연속 중복 방지와 좌우·음량의 작은 변화는 유지합니다.
- 첫 1.8~3.5초, 이후 4.8~10.5초의 기존 간격과 8초 미리 듣기 구조는 유지합니다.

## 유지한 것

승인된 `water-porcelain-bed-v043.mp3`는 바이트 단위로 유지했습니다. SHA256은 `67e7f3288a553381a36392d4f9d171d0592c3e0d0fb3c1b2c2f275468d78a263`이며 회귀 검사에 고정했습니다. 숲 소리, 안내 음성, 대본과 디자인은 변경하지 않았습니다.

## 제작과 출처

`python3 tools/audio/soft_porcelain.py`로 재현합니다(numpy, ffmpeg/rubberband 필요). 기존 CC0 ceramicCups2/kikuchiyo 녹음과 승인된 물 파일이 입력입니다. 해당 녹음의 출처는 PORCELAIN_WATER.md와 AUDIO_REMIX.md에 있습니다. 낮은 공명은 이 앱을 위해 코드로 만든 독립 합성음이며, 클리나멘 영상의 원음은 사용하지 않았습니다. 앱 소개에도 녹음 가공과 합성 공명을 구분했습니다.

새 파일은 soft-middle/low/high-v044 3종입니다. 물 파일 경로는 v043 그대로입니다. `water-and-soft-porcelain-review-v044.mp3`는 기본 자연음 35%로 고정 배치한 30초 검토 믹스이며, 실제 세션의 불규칙한 배치와 구분합니다.

## 검증과 한계

모든 MP3를 다시 디코딩해 길이, 유한한 비제로 파형과 peak<1을 확인했습니다. 공명 파일은 peak<0.3, 2kHz 초과 에너지 비율<0.001을 자동 확인했습니다. 상세 수치는 soft-porcelain-checks.json에 있습니다. 물 파일 동일성 및 기존 오디오 회귀 검사를 포함한 18개 테스트가 통과했습니다.

실제 휴대폰 청취와 주관적인 자연스러움, ‘두웅’ 여운의 적합성은 미검증입니다. 수치나 재생 시작 이벤트를 청취 성공으로 보고하지 않습니다. 특정 작품의 소리를 동일하게 재현했다고 주장하지 않습니다.
