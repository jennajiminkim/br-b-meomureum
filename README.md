# 머무름 / MEOMUREUM · Web v0.3

> 마음을 바꾸려 하지 않아도 괜찮아요.

자연의 소리와 짧은 안내 속에서 잠시 머물 수 있는 **반응형 마음챙김 웹 앱**입니다. 마음을 고치거나 통제하는 목표를 부여하지 않습니다. 로그인, 감정 입력, 이력, 점수, 배지, 연속 기록, 분석, 서버 API가 없습니다. 명상과 뇌 기능 변화에 대한 관심에서 출발했지만, 의료적 치료를 대체하지 않는 **비치료적 보조 도구**입니다.

## 실행

```sh
python3 -m http.server 8000 --directory dist
```

`http://localhost:8000`을 엽니다. ES 모듈을 사용하므로 HTML 파일을 더블클릭해 여는 방식은 지원하지 않습니다. `dist/` 내용만 정적 호스팅에 올릴 수 있습니다. 설치·빌드·API 키·데이터베이스가 필요하지 않습니다. 폰트·포스터는 외부 서버에서 가져오지 않습니다.

## 현재 구현

- 홈 갤러리 → 공간 선택 → 설정 → 명상 → 완료 / 중간 종료.
- 물결과 울림: 하얀 도자기 2개와 맑은 청록빛 수면 클로즈업. 기존 CSS 타원 도자기를 제거했습니다.
- 숲의 숨결 — 제주: 촉촉한 초록과 따뜻한 아침 햇빛의 콘셉트 포스터. **실제 제주 촬영 사진이 아닙니다.**
- 홈에서는 무음으로 시작합니다. 소리 활성화 후 마우스로 카드에 0.7초 머물면 미리 듣기. 모바일·키보드에서는 명시적인 8초 미리 듣기 버튼을 사용합니다. 카드에서 벗어나면 정지합니다.
- 미리 듣기 1.7초에 도자기 울림 또는 새소리를 강제로 배치합니다. 8초 뒤 정지합니다.
- 3개 프로그램 × 3·5·10분, 총 9개 대본. 가이드 전체 On/Off, 음성·자막·음성+자막 선택.
- 동일한 시간표로 자막·음성 구간을 시작하고 구간 끝에서 안내를 비웁니다. 나머지는 침묵입니다. 정확한 문장과 구간은 `docs/GUIDE_TIMELINES.md`, 기계 판독 데이터는 `docs/guide-timelines.json`입니다.
- 일시정지·재개, 세션 중 공간 변경, 가이드 변경, 자연음 음량, 동작 감소, 조작 메뉴 항상 표시.
- 공간 변경은 시계·대본 위치를 초기화하지 않습니다. 설정 패널을 여는 동안 세션을 잠시 멈춥니다.
- 완료(`complete`)와 중간 종료(`early`)는 메모리의 `SessionClock.reason`으로 구분합니다. 어느 경우도 평가·성공·실패 표현을 쓰지 않습니다.
- 비동기 음원 시작의 취소 토큰, 미리 듣기/세션 분리, 공간 변경 시 이전 효과음 분리, 배경음만 짧게 교차 전환.
- 모달 키보드 포커스 순환·복귀, Escape 닫기, 열린 세션 모달 뒤의 조작 비활성화.
- 다른 탭/앱으로 이동해 문서가 숨겨지면 자동으로 일시정지합니다. 백그라운드 명상을 계속 재생하는 정책이 아닙니다.

## 임시 처리 / 교체할 에셋

| 구분 | 현재 | 실제 교체 대상 |
|---|---|---|
| 물결 배경 | AI 포스터 기반 웹 애니메이션 | 고정 카메라의 20~40초 무음 mp4/webm 루프. 도자기 1~2개, 맑은 청록빛 수면과 은은한 깊이, 미세한 반사 |
| 숲 배경 | AI 포스터 + 햇살·낙엽·새 애니메이션 | 밝은 제주 아침 숲의 실제 루프 영상. 시선 정면, 카메라 고정, 빛과 잎만 미세한 움직임 |
| 자연음 바탕 | 사용 권한 확인한 현장 녹음, 보정·루프 편집 | 실제 청취 후 최종 믹싱. 숲은 제주 녹음으로 교체 가능 |
| 작은 소리 | 현장 새소리 + 자체 합성 도자기 | 도자기는 실제 녹음 교체 필요. 간격·좌우 위치 제한 무작위 |
| 음성 | 9개 세션: 같은 화자의 사전 제작 한국어 파일55개(63개 cue) | 전체 프로그램의 발음·음색 실제 청취 확인 |

**현재는 포스터를 분리한 웹 애니메이션으로 움직입니다.** 영상이 없는 상태를 영상처럼 속이거나 평면 도자기 도형으로 메우지 않습니다. 화면에 ‘포스터 애니메이션’을 표시합니다. 두 포스터의 생성 사양은 `docs/ASSET_BRIEF.md`에 있습니다.

### 영상과 자연음 교체

1. 사용 권리를 확인한 파일을 `dist/assets/`에 추가합니다.
2. `dist/assets.js`의 해당 공간 `video.mp4`, `video.webm`, `audio.bed`, `audio.accent`를 설정합니다. 예: `video.mp4: './assets/water-loop.mp4'`.
3. 영상은 무음·loop·playsinline으로 재생되고, 일시정지·동작 감소에서는 멈춥니다. 영상이 재생되지 않으면 포스터가 유지됩니다. 빈 경로는 요청하지 않습니다.
4. 자연음 경로는 자동 디코딩·캐시됩니다. 파일이 없거나 실패하면 오류를 표시하고 세션을 멈춥니다. 합성 노이즈로 조용히 대체하지 않습니다. bed는 루프가 깨끗해야 하고 accent는 짧아야 합니다. 새 음원은 실제 청감 테스트 후 미리 듣기의 대표 소리를 확인하세요.
5. 실제 에셋 교체 시 화면의 ‘포스터·합성음’ 표시와 설정 안내·출처 문구도 함께 갱신합니다. 현재 표시는 포스터 애니메이션 버전에 맞춘 고정 문구입니다.

음성 파일 연결·타이밍·제작 출처·검증 한계는 [오디오 개발 메모](docs/AUDIO.md)에 정리했습니다.

## 파일 구조

- `dist/index.html`: 홈·설정·세션·종료 화면.

## 개인정보

세션 상태는 현재 탭의 메모리에만 있습니다. localStorage·쿠키·IndexedDB·분석 SDK·개인화 서버를 사용하지 않습니다. 새로고침하면 초기화되고 홈 복귀 시 세션 시간·종료 사유를 지웁니다. 호스팅 서비스의 통상적인 접속 로그는 앱의 명상 기록과 별개입니다.

## 확인이 필요한 UX

- 실제 iOS Safari·Android Chrome의 오디오 잠금 해제, 기기 음성 설치, 전화·화면 잠금 이후 상태.
- 모든9종은 자체 포함 음성을 사용합니다. 파일이 없거나 실패하면 오류를 표시하고 사용자가 재시도 또는 자막을 선택합니다.
- 사전 제작 음성은 현재 문장 내 재생 위치에서 재개합니다. 모든9종에 같은 재개 방식을 적용합니다.
- 내레이션의 속도·음색·침묵 길이와 자연음 믹스의 청감은 실제 사용자 검토가 필요합니다.
- 모바일 세로 크롭에서 도자기·숲 중앙 구도가 충분히 보이는지.
- 선택한 실제 영상의 루프 접합, 밝기, 움직임, 대역폭·배터리 사용량.
- 빠른 공간 변경 때 배경음 교차 전환은 의도된 혼합이며, 도자기/새 효과음은 이전 공간의 버스를 분리합니다.

`node --test tests/*.test.mjs`로 자동 검사를 실행합니다. 브라우저 검증 범위와 제한은 `docs/QA.md`를 참고하세요.

## v0.3 · 포스터 기반 움직임

추가 유료 영상 서비스나 외부 패키지 없이 브라우저에서 직접 그립니다. 실제 촬영·생성 MP4가 아니며 수면 유체 시뮬레이션도 아닙니다.

- 물: 원래 포스터에서 도자기 두 개를 SVG 경로로 분리하고, 그릇을 제거한 물 배경(`dist/assets/water-surface-aqua.webp`) 위에 합성합니다. 그릇은 각자 다른 위상으로 약 3~4px 상하, 7~10px 좌우(원본 이미지 좌표) 이동하며 아주 작게 회전합니다. 물결만 WebGL 텍스처 왜곡으로 움직이고, 지원하지 않는 기기는 Canvas 2D 스트립 변형으로 대신합니다. 두 경로 모두 실패하면 원래 포스터를 표시합니다.
- 숲: 원본 사진의 카메라 구도를 고정하고 빛 레이어만 14~19초 주기로 천천히 변합니다. 작은 낙엽 2개는 각각 43/57초 주기로 나타났다가 사라집니다. 새 3마리의 작은 실루엣은 약 76초 주기 중 약 9초 동안 중앙을 통과합니다. 동물의 사진·실제 비행 영상은 아닙니다.
- 현재 화면과 선택한 공간만 실행합니다. 홈에서는 보이는 두 카드, 설정·명상에서는 선택한 공간만 움직이며 완료 화면은 정지합니다. IntersectionObserver로 화면 밖은 중지합니다.
- 세션 일시정지·설정 패널을 열면 움직임도 정지하며 재개 후 이어집니다. 문서가 숨겨진 경우 중지하고, OS의 reduced-motion 또는 앱 ‘움직임 줄이기’ 설정에서는 정지 포스터로 대체합니다.
- 수면은 최대 1440px 폭·약 30fps로 그리며, 숲은 주로 CSS 레이어를 사용합니다. 낮은 성능의 기기에서는 움직임 줄이기를 권장합니다. 고성능 모바일을 포함한 실제 기기 성능 검사는 별도입니다.
- 조정 위치: `dist/motion.js`의 물결 속도·그릇 이동폭·클립 경로, `dist/styles.css`의 sunbeam-drift/leaf-fall/bird-passage.
- 원본 대비 한계: 도자기 내부 반사·그림자는 실시간 물리 연산이 아니며 원래 이미지 일부입니다. 아주 작은 이동폭을 사용해 합성의 어색함을 줄였습니다. 새는 사실적인 동영상 대신 작은 벡터 실루엣입니다.

실제 영상을 나중에 연결하면 웹 애니메이션은 숨겨져 중첩되지 않습니다.

### v0.3.1 햇살 가시성 조정

밝은 원본 숲에 묻히던 햇살의 농도와 이동폭을 높였습니다. 주 빛 띠는 14초에 한 방향으로 이동한 뒤 되돌아오며, 보조 빛은 19초, 넓은 빛 번짐은 17초에 걸쳐 천천히 변합니다. 이전보다 이동폭을 약 7배 넓혔고 기존의 일시정지·움직임 줄이기 동작은 유지합니다.

## v0.4 · 오디오 수정 후보 (실제 모바일 청취 검증 대기)

디자인·배경·대본은 유지했습니다. 한국어 음성 목록 지연과 음성 실패의 무응답을 처리하고, 호흡 5분을 브라우저 TTS 대신 자체 포함 MP3로 연결했습니다. 안내/자연음 음량은 독립적이며 발화 중 배경을 낮춥니다. 현장 물·숲·새소리를 연결하고 필터 노이즈 경로는 제거했습니다. 상세 변경·라이선스·남은 검증은 [AUDIO.md](docs/AUDIO.md)를 보세요. **휴대폰에서 들린다는 검증은 아직 하지 않았으므로 해결 완료로 간주하지 않습니다.**


## v0.4.2 안내 목소리 통일

모든3/5/10분 안내를 같은KR화자로 사전 제작했습니다. 기존보다 약3.4% 낮은피치이며 속도와 대본·침묵은 유지합니다. 다른 기기 목소리로 바뀌는 speechSynthesis 경로를 제거했습니다. 자막창은 각파일의 실제 길이에 맞췄습니다. 상세출처·검증·재현방법은 [VOICE_UNIFICATION.md](docs/VOICE_UNIFICATION.md)를 보세요.
